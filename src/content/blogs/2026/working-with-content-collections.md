# Working with Content Collections

Content collections are one of the most useful features in Astro for blogs and documentation sites. Instead of hard-coding article data, you can store frontmatter and markdown files in a structured location.

## Benefits

- consistent metadata
- easier filtering and sorting
- cleaner templates
- better maintainability

## Example workflow

Create a folder for your posts, add frontmatter with the title and date, then query them with `getCollection`. This makes it easy to build a homepage, archive, and individual post pages without duplication.
