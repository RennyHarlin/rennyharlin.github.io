# First Steps in Astro

Astro is a powerful framework for building fast content-driven websites. It shines when you want simple pages, static generation, and minimal JavaScript by default.

## Why people like it

- Fast page loads
- Great for content sites
- Flexible component support
- Easy content collections

## Getting started

Start by creating a new project and then define your routes and content. For a blog, the content layer is especially useful because your posts can live in Markdown files and be rendered with a layout.

This is a good place to test the blog listing experience before adding more advanced features like tags, search, or pagination.
